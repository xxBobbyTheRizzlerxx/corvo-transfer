# Corvo Transfer

The page a phone, laptop or Mac opens (from a QR code in Corvo's Transfer tab) to send and receive files with Corvo on a Windows PC from any network.

Files go directly between the two devices over encrypted WebRTC ([Trystero](https://github.com/dmotz/trystero)); public Nostr relays only carry the encrypted introduction. Nothing is uploaded or stored here.

Built from `transfer-web/` in the Corvo repo; don't edit by hand.
